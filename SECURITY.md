# Güvenlik Politikası

## Desteklenen sürümler

| Sürüm | Destek |
| --- | --- |
| `1.0.x` (en güncel) | Evet — yalnızca en güncel küçük sürüm |
| Daha eskileri | Hayır — güvenlik düzeltmeleri güncel sürüme alınır |

## Zafiyet bildirme

Güvenlik açığı bulduysanız **önce** şu yollardan biriyle bildirin:

- Bu repoda **Security → Private vulnerability reporting** (gizli güvenlik
  uyarısı), veya
- `security@deva.app` adresine e-posta.

Lütfen şunları içermesin:

- Ezberlenmiş kriptoanalizi anlatan spekülasyon yerine çalışan kanıt
  (adım adım çoğaltım, etki, önerilen düzeltme).
- Kullanıcı verisi veya gerçek kurum kaydı içeren hiçbir şey — sentetik
  örnekler kullanın.

## Beklenti

- **Onay:** 3 iş günü içinde alındı onayı.
- **Yayınlama:** Uyumlu bildirimin ardından, bildiriciyle koordine edilen
  zamanda yama + sürüm notu çıkarılır.
- **Teşekkür:** Bildirenlerin adları (izin verirseniz) sürüm notlarında
  anılır.

## Kapsam notları

DEVA tanı koymaz ve tedavi önermez; kriz mesajları bilgilendirme amaçlıdır.
Bu politika, uygulama ve backend güvenlik açısından geçerlidir; klinik
etkinlik iddialarını kapsamaz.
